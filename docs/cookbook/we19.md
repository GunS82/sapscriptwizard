# WE19 upload example

```python
from pathlib import Path
from sapscriptwizard import SapSession
from sapscriptwizard.features.we19 import WE19

session = SapSession()
session.connect()
window = session.window()
WE19(window).upload_xml("wnd[0]/usr/txtXML", Path("input.xml")).execute("wnd[0]/tbar[1]/btn[17]")
```
